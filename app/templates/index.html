RF collection diagnostics

Active spectrum scan safety
Active off-channel scanning is not run automatically. The supplied official Network API documentation does not expose a documented RF scan command, and an undocumented scan can interrupt clients. The app will keep active scanning disabled until the exact controller/AP command is separately verified.

Channel Planner

Analyzes your AP channel layout, retry trends and proven overlap between your own APs.
Safe advisory mode: the planner uses passive current-channel RF telemetry when your controller exposes it, alongside retry history and own-AP overlap. Raw neighboring signal fields are diagnostic only and are not used to select or score a channel until their controller semantics are independently validated. Active/off-channel scanning remains disabled until its controller-specific command is separately verified. Radio changes still use the gated A/B/A workflow rather than silent tuning.

Coordinated RF target plan

Shows the intended end-state across all APs so individual changes do not accidentally create a temporary long-term conflict.

Before / after tests

Wi-Fi revalidation policy

Audit policy

PASS means the current data supports a healthy configuration. REVIEW means the setting is context-dependent and deserves confirmation, not that it is wrong. WARNING and CRITICAL are reserved for stronger evidence such as offline devices, duplicate active IPs, open/unverified Wi-Fi security, or broad allow policies. Automatic configuration changes are intentionally disabled on this page.

How this score works

A 100 Mbps link is not automatically considered bad. Use Set expected speed on a port after you confirm the endpoint capability. The app remembers that expectation and will stop penalizing a matching link, but still warns if the link later falls below the expected speed, flaps, accumulates new errors/drops, or develops a PoE fault.
